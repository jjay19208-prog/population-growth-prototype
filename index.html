Models used

Exponential: dP/dt = rP, so P(t) = P₀ ert. Growth has no limit.
Logistic: dP/dt = rP(1 − P/K), so P(t) = K / [1 + ((K − P₀)/P₀) e−rt]. Growth slows as the population approaches K.

Assumptions: one population, constant r and K, no migration. This is an educational prototype, and its results are illustrations, not official forecasts. Valid inputs need P₀ > 0, r > 0, K > P₀, T > 0 and an interval > 0.
